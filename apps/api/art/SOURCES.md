# Where the art came from

Served by the API at `/art/<file>` (see `apps/api/src/web.ts`, `serveArt`). Each file is the
Lovart render below, resized to 1536 on the long side and saved as JPEG at quality 85 with
macOS `sips`; the originals were 1536×2048 PNG at 3 to 5 MB each. Prompts and the choices
behind each image are in `docs/art-prompts.md`. `placeholder.png` is a plain dark 3:4 frame
for a card whose art is not made yet.
